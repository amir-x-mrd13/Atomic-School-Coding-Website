راه‌اندازی بک‌اند Supabase

1) در Supabase پروژه خود را باز کنید.
2) از Project Settings > API مقدار Project URL و کلید عمومی anon/publishable را بردارید.
3) فایل supabase-config.js را باز کنید و دو مقدار YOUR_... را جایگزین کنید.
4) فایل supabase-setup.sql را در SQL Editor اجرا کنید.
5) همه فایل‌های این پوشه را در ریشه مخزن GitHub Pages قرار دهید.

امکانات:
- دبیر تکلیف را ثبت می‌کند و همه دانش‌آموزان آن را از دیتابیس می‌بینند.
- دانش‌آموز پاسخ متنی/کد را می‌فرستد و در جدول submissions ذخیره می‌شود.
- دبیر ارسال‌ها را می‌بیند و نتیجه و بازخورد را ثبت می‌کند.
- آموزش‌ها نیز بین همه کاربران مشترک و آنلاین هستند.
- صفحات هر 30 ثانیه اطلاعات جدید را دریافت می‌کنند.

کد نمایشی ورود دبیر همان 62458 است.
توجه: سیاست‌های SQL این نسخه برای راه‌اندازی ساده، دسترسی عمومی می‌دهند؛ برای اطلاعات واقعی دانش‌آموزان باید دسترسی‌ها با Supabase Auth محدود شوند.
